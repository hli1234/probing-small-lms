# Probing small LMs

Source for the Quarto blog *"Notes on what small language models know about the world"* — probes, patches, and pictures from the residual stream.

## Build locally

```bash
quarto preview   # live preview while editing
quarto render    # build the static site into _site/
```

## Publish

The rendered site is hosted on GitHub Pages. To publish (or re-publish after edits):

```bash
quarto publish gh-pages
```

See `PUBLISH.md` for first-time setup.
